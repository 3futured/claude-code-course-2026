A/B prompt testing workflow in VS Code
1. Prepare the workspace

2. Structure each prompt clearly
For both the original prompt and your improved prompt, use the same structure:
Goal / task
What you want the AI to do in one sentence.
Context
Any background details the tool needs to know.
Input
The exact problem, question, or example to solve.
Expected output format
Specify if you want bullet points, a numbered list, code block, summary, etc.
Constraints or tone
e.g. “Keep the answer concise”, “Use plain language”, “Do not add unrelated ideas”.
Example prompt structure:
Goal: “Explain how api.js works in this repo.”
Context: “This is a small Express+Claude agent app.”
Input: “Describe the request flow and the messages array.”
Output format: “Give 3 short paragraphs and a short list of key steps.”
Constraints: “Do not use jargon. Keep it under 120 words.”
